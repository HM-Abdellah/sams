# Archived Legacy UI E2E

These tests target the pre-React PHP-rendered / Vanilla JS frontend.

They are retained as historical behavioral evidence only and are intentionally outside
the active Playwright test directory.

Active frontend coverage lives under tests/e2e:

- Phases 12–21 regression
- Phase 22 legacy replacement is retained as historical acceptance evidence
- Phase 23 production integration

Do not restore these files to tests/e2e without re-validating them against the current
React application and current API contract.
